# Security

This repository is a book and a static website. It runs no server, stores no user data, and collects no analytics of its own.

## Reporting

Report a security problem privately through GitHub's "Report a vulnerability" feature on the repository's Security tab, or email <joel@joelparkerhenderson.com>. Please do not open a public issue for a vulnerability.

The most likely issues are a malicious link in the content, a problem in the site's build workflow or dependencies, or a script in `bin/` that mishandles a file path. Please include the file and what you observed.

## Response

The maintainer aims to acknowledge a report within a week and to say what will be done. This is a one-person project, and no service-level commitment is made.

## Supported versions

Only the current `main` branch and the currently published site are supported.
