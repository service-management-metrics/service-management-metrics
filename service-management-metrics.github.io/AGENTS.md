# AGENTS.md (site)

Guidance for AI agents working in `service-management-metrics.github.io/`. The governing specification is `../spec/index.md`. The site is a published view of the book; it never owns content. Read `README.md` first.

## Rules

- **Use pnpm**, never npm or yarn. `packageManager` is pinned in `package.json`; `pnpm-lock.yaml` and `pnpm-workspace.yaml` are committed.
- **Never edit `src/content/`.** It is generated by `scripts/sync-content.sh`. Fix the source in the monorepo and run `pnpm sync`.
- **Publish only with `bin/deploy-site`** (from the monorepo root). Never push to the site repository directly.
- **Prerendered, always.** `src/routes/+layout.ts` sets `prerender = true`. Every route must be prerenderable; a new dynamic route needs an `entries()` export.
- **Content stays server-side.** Anything reading `src/content/` lives in `src/lib/server/`.
- **Lily components are headless.** They carry class names and no styles. Put all styling in `static/assets/style.css`, never in a component `<style>` block.
- **Lily packages come from npm.** Theme CSS comes from `@lilydesignsystem/themes` via `scripts/sync-themes.sh` (run by `postinstall`), generic default themes only; `static/assets/themes/` is gitignored and generated.
- **UI strings** come from Sveltia I18n: add a key to `src/lib/locales/en-001.json` and use `_('key')` from `#lib/i18n.js`. Never hard-code visible English in a component.
- **`src/lib/locales.ts` must stay a plain module** (no `import.meta.glob`), because `src/params.ts` loads it in Node.
- **Sveltia keeps the active locale in a singleton.** That is safe here because pages are prerendered one at a time at build time and the app runs only in the browser. Do not add a runtime server.

## Before committing

```sh
pnpm check    # 0 errors
pnpm build    # completes; read the prerender warnings
```

Then serve `build/` as plain static files (`cd build && python3 -m http.server 4190`), which is what GitHub Pages does, and check at 1440px and 390px: no horizontal scroll, working theme, text-size, language, and search pickers, and a clean console.

## Things that have bitten before

- **Wide tables** are wrapped in a scrolling `.prose-scroll` region by `markdown.ts`. Do not remove it to "fix" a table.
- **Bare URLs** in references need `.prose a { overflow-wrap: anywhere }`.
- **`LocalePicker`'s `onChange` fires once on mount.** `+layout.svelte` ignores the first call (`readyToNavigate`). Removing that guard makes every load redirect.
- **Keep `@lilydesignsystem/themes` in step with the picker packages.** After a picker-bar upgrade, check `grep -c search-picker static/assets/themes/light.css` is non-zero and rerun `./scripts/sync-themes.sh`.
- **Search** is per locale: `scripts/build-search-index.mjs` writes `build/search-index/<locale>.json`; see `spec/search/index.md`.
