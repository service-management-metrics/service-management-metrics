# 附录

**为运行度量计划的人提供的参考材料：术语、公式、检查清单、模板、自我评估、来源和索引。**

在本部分之前的十一个部分，解释了度量什么，以及如何无害地使用这些测量值。附录是要放在它们旁边的工具。它们不遵循内容主题的模板，因为它们是用来查阅、复制和调整的，而不是从头读到尾的。

这些材料大部分是从前面的主题汇编而来。术语表把每个术语指向其所在的主题。公式参考、汇总的来源和索引，是由各主题中的定义、钻空子表和参考文献清单生成的，所以所在的主题始终是权威，当某个主题变化时，这些附录会被重新生成。检查清单、模板和自我评估，把第 11 部分的建议浓缩成团队可以在一小时内使用的表单。

## 本部分的主题

- **12.1 术语表**：术语和缩略语，各自指向其所在的主题。
- **12.2 度量定义与公式参考**：每项测量值一个条目，附定义、公式、单位、数据来源、钻空子途径和护栏。
- **12.3 检查清单集**：度量评审、仪表盘上线和计划审计。
- **12.4 模板**：度量章程、度量卡、仪表盘规格和评审议程。
- **12.5 成熟度自评**：供团队自我评估的汇总成熟度模型。
- **12.6 参考文献与延伸阅读**：汇总的参考文献。
- **12.7 索引**：按主题编号的概念、框架和测量值。

## 这些主题如何相互关联

术语表（见主题 12.1，术语表）和索引（见主题 12.7，索引）帮助读者找到某个术语或测量值所在的主题。公式参考（见主题 12.2，度量定义与公式参考）是在采用某项测量值之前要查看的地方，因为每个条目都带有其钻空子途径和护栏，而度量卡模板（见主题 12.4，模板）是团队记录自己对某个条目的变体所用的表单。

检查清单（见主题 12.3，检查清单集）和自我评估（见主题 12.5，成熟度自评）是评审计划的两种办法。检查清单评审的是制品：一项测量值、一个仪表盘、一项计划。自我评估评审的是实践，通过一小时的交谈，产生一两个小的下一步。用检查清单为评审做准备，用自我评估来举行评审。来源（见主题 12.6，参考文献与延伸阅读）为两者提供支持，并附有一项提醒：书籍、论文和标准是凭记忆引用的，在正式使用之前应当予以确认。
