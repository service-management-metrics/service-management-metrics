# مقاييس إدارة الخدمات

**قِس إدارة الخدمات دون تشويه العمل.**

كتاب عملي في قياس إدارة الخدمات قياسًا جيدًا عبر أربع عدسات: الأجايل والذكاء الاصطناعي والأتمتة والتحليلات. يسمّي كل مقياس مسار تلاعبه وحاجز الحماية الذي يكشفه. والمقاييس تصف الفرق والخدمات والأنظمة، لا الأفراد أبدًا.
