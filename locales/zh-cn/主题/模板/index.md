# 模板

四份可以复制并调整的模板：度量章程、度量卡、仪表盘规格和评审议程。它们是起点。替换括号中的文字，删去不适合的部分，并尽可能让每份文档保持在一页之内。

## 度量章程

```text
[团队、服务或组织] 的度量章程

目的
我们度量 [服务和工作方式]，以便 [改进…… / 看清…… / 决定……]。
这些测量值帮助我们看到自己的工作并加以改进。它们不是评判个人的办法。

数据用于什么
- 团队评审工作进展如何，以及接下来尝试什么。
- 关于在服务、工具和技能上在哪里投资的决定。
- [监管者/客户] 所要求的报告：[列表，单独保存]。

数据永远不会被用于什么
- 给个人排名或比较个人。
- 个人绩效评审、薪酬、晋升或解雇。
- [加入你的团队提出的担忧。]

谁看到什么
- 每个团队先看到自己的数据，并拥有解释权。
- [角色] 看到聚合的服务和团队趋势。
- 个人层面的视图在 [工具] 中被关闭。

保存的数据
- [收集什么、来自哪些系统、保存多久。]

质疑
- 任何人都可以质疑一个数字。我们在 [数量] 个工作日内回应。
- 联系人：[姓名或小组]。

违反
- 向 [途径] 报告任何违反本章程的使用。结果在不点名的情况下公布。

评审
- 我们每 [六个月] 与团队一起评审本章程。

签署：[赞助者]、[团队代表]   日期：[日期]
```

## 度量卡

```text
度量卡：[测量值名称]

回答的问题：[受众所问的问题]
为之提供依据的决定：[某人可能会有什么不同的做法]
定义：[平实的话]
公式：[如何计算]
单位：[单位]   节奏：[多久一次]
时钟或边界规则：[何时开始、停止、暂停计数]
数据来源：[系统和字段]   刷新：[间隔]
负责人：[角色]   可询问的人：[姓名或小组]
受众：[团队、服务负责人、领导层]
层面：[团队、服务或系统。绝不是个人。]
展示：[中位数和百分位数、运行图、分布]
基线：[来自我们自己数据的期间和值]
已知局限：[缺口、录入习惯的变化、样本量]
钻空子途径：[如何在没有变好的情况下使它看起来更好]
护栏：[配对的测量值或实践]
配套成果：[应当与它一起阅读的成果]
相关主题：（见主题 [N.M]，[标题]）
何时淘汰：[条件]
上次评审：[日期]   自上次评审以来的变化：[笔记]
```

## 仪表盘规格

```text
仪表盘规格：[名称]

受众：[团队、服务负责人、领导层]
负责人：[角色]   评审节奏：[每月或每季度]   评审日期：[日期]
回答的问题
1. [问题]
2. [问题]

测量值（不超过约九项）
| 测量值 | 问题 | 配对的护栏 | 展示 | 来源 | 刷新 |
| [名称] | [编号] | [名称] | [迷你图 / 运行图 / 分布] | [系统] | [间隔] |

随每个值展示的背景
- [期间] 内的趋势、事件说明、定义链接、样本小时的样本量。

状态颜色
- [无，或考虑普通变异的所述规则。]

访问
- [谁可以看到什么。个人层面的视图：关闭。]

数据质量检查
- [新鲜度、行数、与来源的对账。]

淘汰
- 被本仪表盘取代的报告：[列表]，于 [日期] 淘汰。
- 何时淘汰测量值：[条件]。

受众批准：[姓名或角色]   日期：[日期]
```

## 评审议程

一次 45 分钟的团队评审，每月或每季度举行。这是一场关于工作的交谈，由团队主持。

```text
[团队] 的度量评审，[日期]

1. 签到（5 分钟）
   工作进展如何？有什么是数字不会显示的？

2. 自上次以来的事件（5 分钟）
   发布、事件、人员变动、政策变化。在展示上添加说明。

3. 趋势和分布（15 分钟）
   对每项测量值：我们看到了什么？这是普通变异还是信号？
   把每项测量值与其护栏一起阅读。检查数据新鲜度和已知缺口。

4. 决定（10 分钟）
   我们将尝试、停止或改变什么？记录每项决定，包括等待和观察的
   决定。指名负责人和再次查看的日期。

5. 上次的决定（5 分钟）
   上次的决定有帮助吗？我们学到了什么？

6. 测量值本身（5 分钟）
   哪项测量值使我们困惑或误导了我们？哪些可以淘汰？缺少什么？

记录：决定、负责人、日期、对测量值的变更。
规则：不比较个人。数字描述的是系统。
```
