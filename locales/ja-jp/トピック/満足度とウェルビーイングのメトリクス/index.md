# 満足度とウェルビーイングのメトリクス

**安全で、信頼され、自分のペースを保てると感じる人々は、より長く良い仕事をする。したがって、ウェルビーイングについて注意して尋ね、答えを匿名で集約して保ち、学んだことを、人への判断ではなく、仕事を変えるための呼びかけとして扱う。**

## 概要と動機

アジャイル宣言の原則は、アジャイルプロセスが持続可能な開発を促進すると述べています。スポンサー、開発者、ユーザーは、一定のペースを無期限に保てるべきです。また、意欲に満ちた個人を中心にプロジェクトを構成し、彼らが仕事を成し遂げると信頼することも述べています。夜、週末、危機を通じて複雑なシステムを動かし続けるのに人々に依存するサービス組織は、自分たちの働き方が本当に持続できるかを問う必要があります。満足度とウェルビーイングの測定値は、それを問う方法です。

これらの測定値は、この本の他のどの測定値よりも繊細です。人々が自分の仕事、同僚、健康についてどう感じているかに触れます。下手に行えば、プライバシーを侵害し、恐れを生み、偽の答えを生みます。うまく行えば、さもなければ辞職、エラー、インシデントとして現れる問題の早期の警告を、チームとリーダーに与えます。したがって、このトピックは、メトリクスと同じくらい、倫理と方法についてであり、チームの条件についての前のトピックに続きます（トピック 9.1「チームの健全性と開発者体験」を参照）。

三つの考え方がこれを枠づけます。

- **満足度はウェルビーイングではなく、どちらもエンゲージメントではない。** [仕事の満足（job satisfaction）](https://en.wikipedia.org/wiki/Job_satisfaction)は仕事についての人の感じ方、[従業員エンゲージメント（employee engagement）](https://en.wikipedia.org/wiki/Employee_engagement)は仕事への活力ある関与、ウェルビーイングは健康と充実のより広い状態である。人は、自分をすり減らす仕事に満足していることがありうる。一つを測っても、他のことは分からない。
- **意欲は、築ける条件から来る。** エドワード・デシとリチャード・ライアンが発展させた[自己決定理論（self-determination theory）](https://en.wikipedia.org/wiki/Self-determination_theory)は、三つの欲求が満たされるとき、人々の[内発的動機づけ（intrinsic motivation）](https://en.wikipedia.org/wiki/Intrinsic_motivation)が支えられると提案する。自律性、自分の仕事に対する統制の感覚。有能感、効果的であり成長しているという感覚。関係性、他者とのつながりの感覚。これらは、必要な環境と信頼を与えられた意欲のある個人というアジャイルの呼びかけに合う。
- **声を上げる安全は前提条件である。** エイミー・エドモンドソンが発展させた概念である[心理的安全性（psychological safety）](https://en.wikipedia.org/wiki/Psychological_safety)は、チームが対人関係のリスクを取るのに安全であるという共有された信念である。それがなければ、人々は間違い、懸念、疲弊を隠し、あらゆるアンケートは、人々が感じていることではなく、人々があえて言うことを測る。

ウェルビーイングの測定値には、特有の危険があります。回答者は、期待されていると思う答えを与えることがあり、このパターンは[社会的望ましさバイアス（social desirability bias）](https://en.wikipedia.org/wiki/Social_desirability_bias)として知られています。燃え尽きは深刻な問題で、世界保健機関の分類は、バーンアウトを、うまく管理されていない慢性的な職場のストレスから生じる職業上の現象として記述しています。アンケートによってなされる医学的診断ではありません。研究者は燃え尽きを、疲弊、冷笑、効力感の低下を通じて記述し（[燃え尽き症候群（occupational burnout）](https://en.wikipedia.org/wiki/Occupational_burnout)が一般的な用語です）、雇用主は、個人を診断するのではなく、支援を提供して条件を直すべきです。[グッドハートの法則（Goodhart's law）](https://en.wikipedia.org/wiki/Goodhart%27s_law)からの防護柵は、ここでは人間の顔を持ちます。ウェルビーイングのスコアがマネージャーの目標になると、人々は大丈夫だと言うことを学びます（トピック 1.2「グッドハートの法則とメトリクスの心理学」を参照）。

最後の注意です。このトピックは測定の実践を記述し、医学的、心理学的、法的な助言は与えません。産業保健、人事、従業員の代表などの資格のある専門家を関与させ、人々が働く場所に適用されるプライバシーと雇用の法律に従ってください。

## 主要な原則

- **参加は任意で、答えは匿名である。** 誰も、自分がどう感じているかを開示するよう強いられるべきではない。
- **グループでのみ報告する。** 最小のグループサイズを使い、人を特定しうるものはすべて抑制する。
- **これらの測定値で個人を評価しない。** それらは仕事とチームを記述する。
- **決して診断しない。** アンケートは条件を示せるが、臨床的な判断は資格のある専門家に属する。
- **条件を直す。** 貧弱な結果への対応は、作業負荷、プロセス、優先順位を変えることである。
- **チームが保てるペースを目指す。** 短い集中は構わないが、永続的な緊急はそうではない。
- **人々が見られる場所で行動する。** 目に見える変化が、誠実な答えが必要とする信頼を築く。

## 推奨事項

### 最初に基本の規則を定める

**1. 尋ねる前に規則を書く。** 目的、何が集められるか、誰が何を見るか、最小のグループサイズ、データがどのくらい保持されるか、何が決して行われないかを述べます。個々の回答が、レビュー、昇進、懲戒に使われないことを含めます。草稿を、そのような機関があれば従業員の代表と、プライバシーと人事の専門家と共有します。最終的な規則を、誰もが読める場所に公開します。

**2. 参加を任意にし、答えを匿名にする。** 回答していない個人を追いかけてはいけません。識別の欄を要求してはいけません。個人にたどれないアンケートの方法を使い、その主張を誠実にテストします。小さなチームでは、属性の質問が人を特定しうるからです。人々を守るために何をするかを伝え、それを本気で行います。

**3. 産業保健と従業員の支援を関与させる。** アンケートは、支援の代わりではありません。従業員支援プログラムまたはその同等のものが存在し、人々がそこに到達する方法を知り、マネージャーが誰かが問題を打ち明けたときに優しく対応する方法を知っていることを確認します。苦痛を特定して何も提供しないウェルビーイングのプログラムは、ないよりも悪い。

### うまく尋ねる

**4. 少数の、明確で、検証された質問を使う。** 一貫した尺度で評価される少数の記述は、長いフォームよりよく機能します。心理的安全性と自己決定理論の三つの欲求について、研究文献から確立された言い回しを使い、傾向が意味を持つよう、自分たち自身の言葉遣いを安定に保ちます。自由記述のコメントを一つ加え、コメントを全文読みます。

**5. 感情よりも条件について尋ねる。** 「このペースを1年保てる」や「最善の仕事をするために必要なものがある」は、仕事を指します。「どれだけストレスを感じていますか？」は、人を指します。どちらにも役割があり、条件の質問は、誠実に答えやすく、行動しやすい。

**6. 頻度を軽く保つ。** ペースと作業負荷についての毎月の三問のパルスと、安全と欲求についての四半期ごとのパルスで、ほとんどのチームに十分です。アンケート疲れは現実で、長い年次のアンケートは行動が遅くなります。人々が自動操縦で答えないよう、質問を控えめに変え、中核を安定に保ちます。

**7. 結果をまずチームと読む。** 他の誰かの前に、チーム自身の結果をチームと共有し、彼らに解釈させます。リーダーが見るのは、ランキングではなく、チーム間の傾向と、チームが助けを求める障害です。この方法は、チームが文脈を知っているのでより正確で、より敬意があります。

### 感情に加えて、仕事を見る

**8. 認識を、チームレベルの作業負荷の事実と組にする。** ペースと負担の評価を、ローテーションとオンコールの負荷、計画外の仕事の割合、障害のバックログと比較します（トピック 5.7「トイルとオンコールのメトリクス」とトピック 2.9「運用作業と計画外作業」を参照）。計画外の仕事が増えるにつれて評価が下がるなら、直せる原因を見つけたことになります。時間のデータをチームまたはローテーションに集約し、個人を追跡してはいけません。

**9. 持続した過負荷をシステムの問題として扱う。** 時間延長の週が続くことは、計画、人員、優先順位が現実に合っていないことを意味します。個人にもっと回復力を持つよう求めるのではなく、範囲を減らす、人を加える、仕事を取り除く、インシデントの原因を直すことで対応します。短い、選ばれた集中は、終わりのない緊急とは異なり、チームはそれがどちらかを言えます。

**10. 離職のパターンを、注意して見る。** 自発的な離職は遅行のシグナルです。チーム別に、長い期間にわたって見て、退職者が同意した退職の対話のテーマと組み合わせます。小さな数字は大きく振れ、人を特定しうるので、小さなグループを抑制し、単一の退職を証明として読むのは避けます。

### 行動して学ぶ

**11. 述べた時間内に対応し、何が起きたかを人々に伝える。** ウェルビーイングの懸念に短い期間内に対応することをコミットし、行動とその結果を報告します。対応時間がこれを測ります。「今これは変えられません、そしてその理由はこうです」であっても、目に見える対応が、信頼を生かし続けます。

**12. 機能しないものから学ぶ。** 介入の後にスコアが改善しなければ、その理由を問います。再び試す前にチームに耳を傾けます。瞑想アプリや社交イベントなどのウェルネスの付加物を、高すぎる作業負荷を変えることの代わりにするのは避けます。ウェルビーイングは、主に仕事の組織のされ方の性質です。

## 悪用の手口と防護柵

| メトリクス | 悪用のされ方 | 組になる防護柵のメトリクスまたはプラクティス |
| --- | --- | --- |
| 持続可能なペースの評価 | マネージャーが良いスコアを迫る、チームが期待されることを報告する | 匿名性とグループサイズの規則。作業負荷の事実と比較する。コメントを読む |
| 心理的安全性の評価 | 安全なチームにだけアンケートする、スコアを上げる言葉遣いの変更 | 固定の言葉遣いの記録。回答率と構成。インシデントや間違いの報告率と比較する |
| 欲求の支援の評価 | 記述を再定義する、答えを指導する | 安定した言葉遣い。チームが所有する解釈。コメント |
| 作業負荷の負担の評価 | 精査を避けるために報告される負担を下げる、紙の上で範囲を調整する | 計画外の仕事とローテーションの負荷と比較する。隠れた仕事を確認する |
| 持続した時間延長の週 | 時間を記録しない、ローテーションの記録の外に仕事を移す | インシデントのログとチームのコメントと比較する。罰なしに報告できるようにする |
| 自発的な離職と退職のテーマ | 辞職を非自発的として再分類する、退職の対話を誘導する | 明確な分類の規則。独立した退職の対話。長い期間を見る |
| ウェルビーイングのフィードバックへの対応時間 | 行動のない対応を記録する、懸念を素早くクローズする | 対応が意味のあるものとチームが確認する。評価が変わるかを追跡する |

健全な読みは、作業負荷の事実に合う安定または改善するペースの評価、悪い知らせが伝わるほど高い心理的安全性、条件の変更の後に下がる作業負荷の負担、まれで説明のつく時間延長の週、そして自分たちのフィードバックが使われるのを見ていると言うチームです。

## トレードオフ：長所と短所

| 手法 | 強み | 弱み |
| --- | --- | --- |
| 匿名のパルスアンケート | 誠実で、安く、適時 | 個人にフォローアップできない。小さなグループは匿名性を制限する |
| 記名のアンケート | フォローアップできる | 人々が口を閉ざす。プライバシーのリスク |
| 条件に焦点を当てた質問 | 直せる原因を指す | 個人的な事情を見逃す |
| 感情に焦点を当てた質問 | 生きた体験をとらえる | 誤用されやすい。行動しにくい |
| チームレベルの作業負荷のデータ | 客観的で、原因に結び付く | 強い規則がないと監視に滑り込みうる |
| マネージャーとの一対一 | 個人的で、個人の必要に応えられる | マネージャーに依存する。集約できない |
| 年次のエンゲージメント調査 | 時間にわたって比較できる | 遅い。行動率が低い |
| 頻繁な短いパルス | 適時 | 誤用すると疲れる |

散文での答えは、厳格なグループサイズの規則を伴う、匿名で条件に焦点を当てたパルスを使い、チームレベルの作業負荷の事実と組み合わせ、個人への支援にはマネージャーと専門家に頼ることです。個人レベルのウェルビーイングのデータは、メトリクスの範囲外として扱います。

## チームで話し合う問い

**1. 現在のペースを1年間保てるか、保てないなら何が変わらなければならないか？**
誠実な答えを求めます。ファシリテーターは、非難を割り当てずに原因を記録してください。範囲、人員、中断、インシデント。負担を減らす仕事への変更を一つ合意します。答えがイエスなら、何がペースを守っているかを尋ねます。

**2. ここで最後に誰かが問題や間違いを挙げたのはいつで、どう受け止められたか？**
物語を集めます。対応が好奇心か非難かに注意します。何がそれを安全に、あるいは安全でなくするかを話し合います。挙げた人に感謝するなど、問題を挙げやすくする習慣を一つ合意します。

**3. どんな規則があれば、ウェルビーイングのアンケートを信頼できるか？**
規則を一緒に起案します。誰が何を見るか、最小のグループサイズ、何が決して行われないか。約束を疑わせるものは何かを尋ねます。結果は、代表とレビューする、プログラムの規則の最初の草稿です。

**4. 私たちの実践のうち、人々が余分な時間を働くことに依存しているものはどれで、なぜか？**
リリース、引き継ぎ、オンコールを列挙します。それぞれが本当に必要か、何がそれを取り除くかを尋ねます。自動化、プロセス、人員で直すものを一つ選びます。

**5. 同僚が苦しんでいるように見えたら、どうするか？**
存在する支援、そこに到達する方法、各自ができることを話し合います。ファシリテーターは、従業員支援についての情報を用意し、チームが専門的な助けの代わりではないことを明確にしてください。

**6. 前回のフィードバックの回を受けて、何を変えたか？**
記録を確認します。何も変わらなかったなら、その理由を話し合います。オーナーシップの欠如、権限の欠如、あるいは恐れ。オーナーと日付を伴うアクションを一つ合意し、それがどう報告されるかを決めます。

## 四つの視点

### プロダクトとデリバリーのチーム

デリバリーのチームは、締め切りと需要の圧力を負います。自分たちのパルスの質問を設定し、結果を一緒に議論し、計画でペースと作業負荷を公然と挙げるべきです。どのコミットメントが持続可能かを言うのに最適な立場にあり、耳を傾けるリーダーに値します。

### サービスと運用のチーム

運用チームは、オンコール、インシデント、夜間の仕事を担います。ローテーションの負荷をチームのレベルで追跡し、繰り返される原因の修正を求め、休息とカバーの規則を保護として使うべきです。疲弊を、献身のしるしではなく、サービスへのリスクとして扱う文化が必要です。

### リーダーシップとガバナンス

リーダーは期待を設定し、負荷を生む計画を承認します。プライバシーの規則を守り、チームレベルのシグナルに、範囲、人員、優先順位の変更で応え、チームに順位を付ける誘惑に抵抗するべきです。ガバナンスは、支援サービスが存在し、労働時間と健康についての法的義務が満たされ、個人のデータが評価に使われていないことを確認するべきです。

### 顧客とユーザー

ユーザーは、休息を取り、学び、安定したチームから恩恵を受けます。サービスの品質、忍耐、継続性が彼らに依存するからです。また、チームが圧倒されているときにも影響を受けます。遅い回答、より多くの間違い、経験豊富なスタッフの喪失。容量と優先順位についての誠実なコミュニケーションは、彼らに仕える人々を敬意を持って扱うことの一部です。

## 実践：サービスマネジメントの例

地域の通信事業者のサービス運用グループには、ネットワーク、請求、顧客サポートのシステムを24時間体制で運営する八つのチームがあります。以下の数字は例示です。

一つのチームで三件の辞職があった後、責任者は、各チームのスコアを列挙する士気のダッシュボードを求めます。人事と文化の責任者は別のアプローチを提案し、従業員の代表とともにプログラムの規則を書きます。任意で匿名のパルス、7人の最小の報告グループ、個人のデータなし、レビューでの利用なし。チームは、ペース、作業負荷、必要なものがあるという感覚についての毎月の三問のパルスと、心理的安全性と自己決定理論の三つの欲求についての四半期ごとのパルスを受けます。結果はまず各チームに行きます。

最初の四半期は、プラットフォーム運用チームが持続可能なペースを5点満点で2.3と評価し、62パーセントが作業負荷を持続不可能と評価していることを示します。ローテーションの記録は、チームが直近13週のうち9週で時間を延長して働いていたこと、それが一つの老朽化した請求コンポーネントからの繰り返されるインシデントに駆動されていること、そしてキャパシティの4分の1が計画外の仕事に向かっていることを示します。チームの心理的安全性の評価は他より低く、コメントは、コンポーネントについての懸念を挙げたことが、辛抱するよう言われることにつながったと述べています。他のチームはペースを3.4から4.1の間で評価しています。

責任者とチームは四つのアクションに合意します。請求コンポーネントの置き換えが優先順位の一覧で繰り上げられ、チームは余力のあるチームから二人の一時的なエンジニアを受け取ります。ローテーションは、夜間のインシデントの後に休息日を加え、マネージャーがそれを守る責任を負います。コンポーネントについての懸念は記録され、理由とともに2週間以内に答えられます。リーダーは、チームのランキングを求めるのをやめます。二四半期以内に、チームのペースの評価は3.6に上がり、時間延長の週は13週中2週に下がり、心理的安全性は上がります。フィードバックへの対応時間は中央値で11日です。責任者は、取締役会に公表する全社のウェルネススコアを求めます。人事と文化の責任者は、単一のスコアはマネージャーに数字を管理させると説明し、チームの同意を得て、行われたアクションと変更された条件のレポートを提案します。判断は記録されます。あるチームは、結果をチームの外に共有しないよう求め、その要求は認められます。

## アジャイル、AI、自動化、アナリティクス

### アジャイル

持続可能なペースを守り、ウェルビーイングを、匿名で集約して、注意して尋ねます。注意点は、尋ねて行動しないことは、信頼を損なうことです。

### AI

AIは作業負荷と雇用の安定への懸念を変えることがあり、センチメントのツールを個人の監視に使うべきではありません。AIが仕事に与える影響を、匿名のアンケートで直接尋ねます。注意点は、AIで自由記述を分析すると個人を露出させうるため、プライバシーの規則を確認することです。

### 自動化

アンケートの配信とリマインダーを自動化し、解釈は自動化せず、プロセスを回答率と匿名性で測ります。注意点は、個人のウェルビーイングについての自動のアラートは、一線を越えることです。

### アナリティクス

集約した結果を、回答数と最小のグループサイズとともに報告します。これが情報を与える判断は、仕事をどう変えるかです。注意点は、ウェルビーイングのデータは機微なので、アクセスと保持を制限することです。

## 業種別の視点

**スタートアップ。** 強度が高いことはよくあり、集中が通常になるリスクもあります。創業者は持続可能なペースの手本となり、チームが熱くなっているときに気づくことができます。チームが匿名性を守れるほど大きくなったら、対話と非常に短い匿名のパルスに頼ります。

**中小企業。** チームは、何も匿名にならないほど小さいことがあります。そうではないふりをするウェルビーイングのアンケートは行わないでください。定期的で誠実な一対一の対話を使い、支援へのアクセスを提供し、慢性的な時間外のインシデントなど、仕事のパターンの過負荷に注意します。

**大企業。** 規模は、匿名の測定値と傾向の分析を可能にします。また、比較する圧力ももたらします。共通の中核の質問の集合を提供し、チームが自分たちのものを加えられるようにし、グループサイズの規則を守り、従業員の代表を関与させます。支援サービスを見えるようにし、使いやすくします。

**政府・公共部門。** 雇用の保護、労使協議会、労働組合は、アンケートや監視に正式な役割を持つことがよくあります。最初から彼らを関与させ、労働時間と健康についての規則に従い、機微なデータを大きな注意をもって扱います。公務員はしばしば目的に動機づけられており、組織は永続的な過負荷を受け入れることで、その善意につけ込むべきではありません（トピック 8.5「規制対応・行政向け報告」を参照）。

## ビジネスケース：動機、ROI、TCO

コストは控えめです。短いパルスのためのチームの時間、匿名性を保つアンケートのツール、プライバシーのレビューと結果の解釈のための専門家の時間、そして行動する実際のコストで、それは人員、範囲の削減、繰り返される原因を直す投資を意味するかもしれません。従業員支援などの支援サービスにもお金がかかり、持つ価値があります。

見返りは、定着、エラーの減少、より良いサービス、危機の減少を通じて来ます。経験豊富なエンジニアを置き換えるには、採用、オンボーディング、失われた知識のコストがかかります。慢性的な過負荷のもとのチームは、より多くの間違いを犯し、より多くのインシデントを引き起こします。自分たち自身のデータからケースを築きます。数年にわたるチーム別の自発的な離職、置き換えの採用とオンボーディングのコスト、過負荷のチームのインシデントのパターン。出典と関連性をたどれない限り、燃え尽きのコストの研究の引用は避けます。便益が現実のものでありながら切り離しにくいこと、そして倫理的なケースが財務的なケースに依存しないことについて、誠実であってください（トピック 7.7「投資対効果とビジネスケース」を参照）。

## アンチパターンと落とし穴

- **ウェルビーイングのスコアでチームに順位を付ける。** マネージャーが数字を管理するようになる。条件と行動を報告する。
- **記名のアンケート。** 人々が口を閉ざす。匿名性とグループサイズの規則を使う。
- **アンケートのデータから個人を診断する。** 非倫理的で信頼できない。支援を提供し、診断は専門家に任せる。
- **作業負荷の変更の代わりのウェルネスの付加物。** 症状を扱う。負荷を直す。
- **一人あたりの時間を集める。** 監視である。ローテーションとチームレベルの事実を使う。
- **行動のないアンケート。** 人々は答えるのをやめる。目に見えて素早く対応する。
- **結果を業績評価に使う。** 誠実さを終わらせる。書面で禁止する。
- **過負荷を回復力の訓練として扱う。** 負担を個人に置く。システムを変える。

## チェックリスト

- [ ] 書面の規則が、目的、アクセス、グループサイズ、保持、個人への利用の禁止を述べている。
- [ ] 従業員の代表とプライバシーの専門家が規則をレビューしている。
- [ ] 参加が任意で、回答が匿名である。
- [ ] すべての出力に最小の報告グループサイズが適用される。
- [ ] 支援サービスが存在し、全スタッフに知られている。
- [ ] パルスが、少数の安定した明確な質問と一つの自由記述を使う。
- [ ] チームが自分たちの結果を最初に読む。
- [ ] チームレベルの作業負荷の事実が認識と比較され、個人の時間とは決して比較されない。
- [ ] 懸念への対応に述べた時間があり、報告される。
- [ ] どのウェルビーイングのデータも、業績評価、昇進、懲戒に使われない。

## AIプロンプト

**ウェルビーイングのプログラムの規則を起案する。**

```text
[法域または業種] の [組織の種類] のスタッフのウェルビーイングのパルスのプログラムの、平易な言葉の規則を起案してください。目的、任意の参加、匿名性、最小の報告グループサイズ [数]、誰が結果を見るか、保持、レビューでの利用の明確な禁止、利用可能な支援、スタッフが懸念を挙げる方法をカバーしてください。プライバシーの専門家、従業員の代表、産業保健とレビューすべき項目に印を付けてください。法的な結論を出さないでください。前提を列挙してください。
```

**パルスの質問をレビューする。**

```text
以下は、ペース、作業負荷、心理的安全性、意欲についての私たちのパルスの質問です：[貼り付け]。誘導的または二重の言葉遣い、繊細さ、小さなグループで個人を特定するリスクについてレビューしてください。私たちが変えられる条件に焦点を当てた、より短い集合を提案してください。公表された出典を正確に引用しない限り、いかなる言葉遣いについても検証済みと主張しないでください。前提と注意を列挙してください。
```

**コメントを安全に分析する。**

```text
以下は [チームの種類] のパルスからの [数] 件の匿名化したコメントです：[識別できる詳細を除いて貼り付け]。仕事の条件についてのテーマにグループ化し、各テーマを数え、どの条件をチーム、そのリーダー、他のグループが変えられるかを示唆してください。誰かの健康を推測したり、個人を特定したりしないでください。行動する前に人が確認すべきことを教えてください。前提を列挙してください。
```

**過負荷のシグナルへの対応を計画する。**

```text
チームのペースの評価は [値]、時間延長の週は [数] 週中 [数]、計画外の仕事は [割合] です。コメントの原因：[要約]。仕事を変える（範囲、人員、ローテーション、根本原因の修正）対応、チームに何を伝えるか、個人を追跡せずにそれが役立ったかをどう測るかを提案してください。前提と、リーダーシップへのトレードオフを列挙してください。
```

## AIスキル

- [サービスマネジメントメトリクスのスキル](../../../../skills/service-management-metrics-skill/SKILL.md)：ウェルビーイングのメトリクスの、組になる防護柵とプライバシーの規則を探すときに使います。
- [サービスマネジメントメトリクスのメンテナースキル](../../../../skills/service-management-metrics-maintainer-skill/SKILL.md)：ウェルビーイングのメトリクスの項目が、悪用の手口、防護柵、匿名性の規則を備えているかを確認するときに使います。

## 要点

- ペース、作業負荷、安全、支援などの条件を、感情よりも尋ね、答えを匿名で集約して保つ。
- 規則を最初に書いて公開し、結果で個人を判断することの禁止を含める。
- 持続した過負荷を、回復力ではなく、範囲、人員、原因で直すシステムの問題として扱う。
- 認識をチームレベルの作業負荷の事実と比較し、個人の時間とは決して比較しない。
- 目に見えて、述べた時間内に対応し、何が変わったかを人々に伝える。
- 本当の支援サービスを提供し、診断は専門家に任せる。
