# テンプレート

コピーして適応させる四つのテンプレート：メトリクスの憲章、メトリクスカード、ダッシュボードの仕様、レビューの議題。出発点です。括弧内のテキストを置き換え、合わないものは削除し、できるところでは各文書を一ページに保ってください。

## メトリクスの憲章

```text
[チーム、サービス、または組織] のメトリクスの憲章

目的
私たちは [サービスと働き方] を、[改善する／見る／決める……] ために測ります。
測定値は、私たち自身の仕事を見て改善する助けとなります。個人を判断する
方法ではありません。

データが何のためか
- 仕事がどう進んでいるか、次に何を試すかのチームのレビュー。
- サービス、ツール、スキルのどこに投資するかの判断。
- [規制当局／顧客] が求める報告：[一覧。別に保つ]。

データが決して何に使われないか
- 個人のランク付けや比較。
- 個人の業績評価、給与、昇進、解雇。
- [チームが挙げた懸念を加える。]

誰が何を見るか
- 各チームが最初に自分たちのデータを見て、解釈を所有します。
- [役割] が、集約されたサービスとチームの傾向を見ます。
- 個人レベルの見方は [ツール] でオフにされています。

保持されるデータ
- [何が、どのシステムから、どれだけの期間収集されるか。]

異議
- 誰でも数字に異議を唱えられます。私たちは [数] 営業日以内に応答します。
- 連絡先：[名前またはグループ]。

違反
- この憲章に反する利用は [経路] に報告してください。結果は名前なしで
  公表されます。

レビュー
- この憲章を [6か月] ごとにチームとレビューします。

署名：[スポンサー]、[チームの代表]   日付：[日付]
```

## レビューの議題

45分のチームのレビューで、毎月または四半期ごとです。チームが主導する、仕事についての対話です。

```text
[チーム] のメトリクスレビュー、[日付]

1. チェックイン（5分）
   仕事はどう進んでいますか。数字が示さないことはありますか。

2. 前回以降のイベント（5分）
   リリース、インシデント、人員の変更、ポリシーの変更。表示にメモを加える。

3. 傾向と分布（15分）
   各測定値について：何が見えますか。通常の変動ですか、シグナルですか。
   各測定値を防護柵とともに読む。データの鮮度と既知のギャップを確認する。

4. 判断（10分）
   何を試し、やめ、変えますか。待って見守るという判断を含め、各判断を
   記録する。オーナーと、もう一度見る日付を指名する。

5. 前回の判断（5分）
   前回の判断は役立ちましたか。何を学びましたか。

6. 測定値そのもの（5分）
   どの測定値が私たちを混乱させ、あるいは誤解させましたか。どれを廃止できますか。
   何が欠けていますか。

記録：判断、オーナー、日付、測定値の変更。
規則：個人の比較はしない。数字はシステムを記述する。
```
